# ПСГИ — электротехническая лаборатория

Версия 17, обновление 15.11.2026. Опубликованное приложение: https://olga-puzanova.github.io/electroprotocol/.

Статическое PWA на HTML/CSS/JavaScript. Используется прежнее хранилище IndexedDB `electro`, версия 2: обновление не меняет и не очищает существующие данные. Создание PDF происходит на устройстве с локальными pdf-lib, fontkit и Noto Sans; библиотеки, шрифт и шесть руководств сохраняются сервис-воркером для работы без сети. Лицензии библиотек находятся в `vendor/`.

Добавлены мастер, подготовка работ, журналы СИЗ/обучения, возврат на доработку, адресные задания, история оборудования и тепловизионные отметки на карте. Доступны резервное копирование и восстановление, нижнее меню, голосовой ввод при поддержке браузером, 50 рационализаторских предложений с сохраняемым планом пробного внедрения. Полный перечень — CHANGELOG.md и раздел «Что нового» в приложении.

Данные, роли, измерения и журналы остаются локальными. Настоящая синхронизация заявок и протоколов между телефонами пока не подключена. Для переноса данных использовать «Разделы → Данные и копии». Папка [server](server/README.md) содержит подготовленный сервер общего чата и ИИ с инструкцией по размещению; на GitHub Pages он не запускается. Для живого чата нужны отдельный сервер и учётные записи, для ответов ИИ — также подключение выбранного сервиса.

В библиотеке шесть PDF: Е6-24, ПТФ-1, ИКС-30А, KEW 6016, MPI-530 (IT), АИД-70Ц. Варианты исполнения MPI-530 и АИД требуют сверки с конкретным прибором. Для СВИ-100/140 найдено описание производителя, открытый PDF руководства не найден. Это не паспорт, заполненный на конкретный заводской номер; такой паспорт прикрепляется отдельно.

Новости включаются в обновления с первоисточником; автоматический сбор новостей не запущен. СКРТ не подключена: требуется название системы и доступ. Нормативные тексты старой версии не переутверждались; новые формы импульсных испытаний и освидетельствования не подбирают режимы автоматически.
